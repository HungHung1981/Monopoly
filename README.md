# Monopoly

A simple Monopoly game. You can play with human or computer players. With code by Matthew Simon, Anmol Kabra, Jehron Petty, Jared Junyoung Kim and Marina Chang. I let Visual Studio Code and its Copilot connected two repositories to play with an AI on the board of the other repository. Thanks to JC and them.

During a game, press `4` to view the board as a rectangular map. Spaces follow
the order defined by the selected board file, so custom boards are displayed
around the same perimeter layout as the classic board.

### How to play ###

Unix/Linux:

Just run ./main.byte

Windows:

Use WSL to run it.
